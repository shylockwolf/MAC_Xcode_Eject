# Eject - 外置存储设备自动弹出工具

[![Platform](https://img.shields.io/badge/platform-macOS-blue.svg)](https://github.com/yourusername/Eject) [![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

一个简单易用的macOS应用程序，用于自动检测并安全弹出所有连接的外置存储设备，保护您的数据安全。

## 功能特点

- 🖥️ **自动检测**：启动时自动扫描所有挂载的存储设备
- 📊 **设备列表**：清晰展示所有挂载设备和已弹出的外置设备
- ⚡ **智能弹出**：自动弹出所有检测到的外置存储设备，无需手动操作
- 📋 **详细日志**：实时显示弹出过程的详细信息和状态
- 🎨 **简洁界面**：使用SwiftUI构建的现代化、直观的用户界面
- 🔒 **安全操作**：遵循标准的设备弹出流程，保护数据完整性

## 技术实现

- **开发语言**：Swift
- **UI框架**：SwiftUI
- **系统交互**：通过shell命令与macOS系统交互
- **异步处理**：使用GCD进行后台任务处理，保持界面响应

## 核心功能

### 设备扫描
- 使用`mount`命令获取所有挂载设备信息
- 过滤出位于`/Volumes/`目录下的外置设备
- 排除系统卷`/System/Volumes/`

### 设备弹出流程
1. 先使用`diskutil unmount`卸载卷
2. 短暂延迟后使用`diskutil eject`弹出磁盘
3. 验证弹出结果
4. 重新扫描设备状态

### 界面展示
- 显示所有挂载设备列表
- 显示已弹出的外置设备
- 实时更新操作日志
- 提供进度指示

## 使用方法

### 快速使用
1. 下载并安装应用程序
2. 直接运行`Eject.app`
3. 应用会自动开始扫描所有挂载的存储设备
4. 自动弹出所有检测到的外置存储设备
5. 在应用窗口中查看操作结果和详细日志

### 适用场景
- 下班前快速弹出所有外置设备
- 会议结束后整理设备
- 避免手动逐个弹出设备的繁琐操作
- 确保所有设备都安全弹出，防止数据丢失

## 构建与安装

### 从源码构建
1. 克隆或下载项目代码
2. 使用Xcode打开`Eject.xcodeproj`
3. 选择适当的开发团队（用于签名）
4. 点击"Build"按钮或使用快捷键`⌘B`构建项目
5. 构建成功后，点击"Run"按钮或使用快捷键`⌘R`运行应用

### 直接运行
构建成功后，可在以下路径找到应用程序：
```
~/Library/Developer/Xcode/DerivedData/Eject-*/Build/Products/Debug/Eject.app
```

## 注意事项

- 应用需要访问系统磁盘管理权限，首次运行可能需要授权
- 请确保在弹出设备前已保存所有正在进行的操作，避免数据丢失
- 对于加密设备或正在被其他应用使用的设备，可能需要额外的用户确认
- 如果设备无法弹出，应用会记录详细信息，方便问题排查

## 故障排除

### 设备无法弹出
- 检查设备是否被其他应用程序占用
- 确认已关闭所有使用该设备的文件和应用
- 尝试手动弹出设备后重新运行应用

### 应用无响应
- 强制退出应用程序并重新启动
- 检查是否有系统更新可用
- 查看应用日志以获取更多信息
